# Projeto 4 - Versionamento e Acessibilidade

## Descrição
Projeto acadêmico desenvolvido para aplicar conceitos de desenvolvimento front-end, versionamento e acessibilidade na Web.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Acessibilidade
O projeto utiliza elementos HTML semânticos, atributos ARIA, navegação por teclado e boas práticas de contraste de cores, seguindo recomendações de acessibilidade da WCAG.

## Estrutura do projeto
- index.html - estrutura e conteúdo da página
- style.css - estilos e apresentação visual
- script.js - interatividade da aplicação

## Objetivo
Desenvolver uma aplicação Web organizada, acessível e preparada para versionamento e publicação em ambiente de produção.
